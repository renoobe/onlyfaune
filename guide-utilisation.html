1. Qu'est-ce que OnlyFaune ?

OnlyFaune est une extension Twitch conçue pour les streams d'observation de la faune sauvage. Elle permet de :

📋
Guide des espèces
Afficher les animaux susceptibles d'être observés, avec photo, description et infos détaillées.
✅
Observations en direct
Signaler une observation en un tap — les viewers voient une alerte plein écran en temps réel.
🗺️
Carte
Montrer la zone d'observation sur une carte OpenStreetMap.
📊
Statistiques
Suivre les observations de la session et l'historique toutes sessions confondues.

L'extension se compose de deux interfaces :

  • Le panneau Admin — utilisé par l'opérateur (vous) sur iPad ou ordinateur pendant le stream
  • Le panneau Viewer — visible par les spectateurs directement sur la page Twitch

2. Avant de commencer

Ce dont vous avez besoin

  • Un appareil connecté à Internet (iPad, téléphone ou ordinateur)
  • Un navigateur web (Safari, Chrome, Firefox...)
  • L'adresse du panneau admin (fournie par le streamer)

Accès au panneau admin

Ouvrez le lien suivant dans votre navigateur :

https://renoobe.github.io/onlyfaune/admin.html
Conseil iPad
Ajoutez la page à l'écran d'accueil pour un accès rapide : dans Safari, touchez l'icône de partage puis "Sur l'écran d'accueil".

3. Créer une session d'observation

Quand vous arrivez sur le panneau admin, vous voyez le formulaire de création de session.

1
Titre de la session
Donnez un nom à votre session, par exemple : "Forêt de Chizé — Aube" ou "Marais Poitevin — Nocturne".
2
Localisation
Deux options :
  • Bouton "Ma position" — utilise le GPS de votre appareil (le navigateur demandera l'autorisation)
  • Champ texte — entrez le nom du lieu manuellement
Vous pouvez aussi cliquer/toucher la carte pour placer un marqueur manuellement.
3
Sélection des espèces
Choisissez les espèces que vous pourriez observer durant cette session :
  • Tout sélectionner — ajoute toutes les espèces d'un coup
  • Basculer — sélectionne/désélectionne une catégorie entière
  • Cliquer sur une fiche — ajoute ou retire une espèce individuelle
  • Recherche — filtrez par nom pour trouver rapidement une espèce
4
Démarrer la session
Appuyez sur le gros bouton doré "Démarrer la session". Le panneau bascule immédiatement en mode observation. Les viewers qui ont l'extension voient la session apparaître en temps réel.
Important
Il ne peut y avoir qu'une seule session active à la fois. Si vous démarrez une nouvelle session, assurez-vous que la précédente est bien terminée.

4. Pendant le stream — Observer

Une fois la session démarrée, vous voyez l'interface d'observation avec trois onglets.

Onglet "Observer"

C'est l'onglet principal. Vous voyez la grille de toutes les espèces sélectionnées pour cette session.

A
Signaler une observation
Dès que vous observez un animal, appuyez sur le bouton vert "VU !" sous la fiche correspondante.
  • La fiche passe en surbrillance dorée avec l'heure d'observation
  • Le compteur en haut se met à jour (ex : "3/12")
  • Les viewers reçoivent une alerte animée en temps réel
  • Vous pouvez observer la même espèce plusieurs fois (bouton "Revoir")
B
Voir le détail d'une espèce
Touchez la photo ou le nom d'une fiche pour ouvrir sa fiche détaillée (habitat, taille, régime, lien Wikipedia...).
C
Rechercher
La barre de recherche en haut filtre les espèces en temps réel. Pratique pour trouver rapidement un animal dans une longue liste.
Conseil terrain
Le journal en bas de l'onglet Observer affiche la liste chronologique de toutes vos observations de la session. Utile pour ne pas oublier ce que vous avez déjà signalé.

Onglet "Carte"

Affiche la carte avec votre position d'observation. Même carte que celle vue par les spectateurs.

Onglet "Historique"

Affiche toutes vos observations, toutes sessions confondues. Vous y trouverez :

  • Le nombre total d'espèces différentes observées
  • Le nombre total d'observations
  • La liste classée par fréquence d'observation

5. Ce que les viewers voient

Les spectateurs voient un panneau compact sous le stream avec trois onglets :

📖
Guide
Grille des espèces : les non-observées sont en gris, les observées en couleur avec l'heure. Cliquer ouvre la fiche détaillée.
🗺️
Carte
Carte OpenStreetMap avec la zone d'observation.
📊
Stats
Compteur d'espèces, nombre d'observations, durée de session, dernières observations.
🚨
Alerte d'observation
Quand vous signalez une observation, une alerte plein écran prend tout le panneau pendant 5 secondes avec la photo en grand et le nom de l'animal. La fiche de l'animal s'illumine également.

Quand aucune session n'est active, les viewers voient simplement un message "Aucune session d'observation en cours".

6. Après le stream

1
Terminer la session
Appuyez sur le bouton rouge "Terminer" en haut à droite du panneau admin. Une confirmation vous sera demandée. La session passe en inactif et le panneau viewer affiche "Aucune session en cours".
2
Les données sont conservées
Toutes les observations sont enregistrées dans la base de données. Elles apparaissent dans l'onglet Historique et seront disponibles pour les prochaines sessions.
Bon à savoir
Vous pouvez fermer le navigateur sans problème. La session reste active tant que vous ne cliquez pas sur "Terminer". Si vous rouvrez le panneau admin, il retrouvera automatiquement la session en cours.

Tester sans être en stream

Vous pouvez tester l'ensemble du système sans être en live :

  1. Ouvrez admin.html sur un appareil (ou onglet)
  2. Ouvrez panel.html sur un autre appareil (ou onglet)
  3. Créez une session dans l'admin
  4. Observez : le panneau viewer se met à jour en temps réel

Signaler une observation Bouton vert "VU !" sur la fiche de l'animal
Voir les détails Toucher la photo ou le nom de l'animal
